# 문법
|               | な형용사^[な형용사는 명사를 꾸며줄 때 な가 사용되어 な형용사라 합니다.] | い형용사                 |
| ------------- | ----------------------------------------- | -------------------- |
| 기본형           | ~だ                                        | ~い                   |
| 정중형(~해요,~합니다) | (기본형의 だ를 떼고)です                            | です                   |
| 정중형의 부정       | (기본형의 だ를 떼고)じゃ　ないです                       | (기본형의 い를 떼고)く　ないです   |
| 과거형           | (기본형의 だ를 떼고)でした                           | (기본형의 い를 떼고)かったです    |
| 과거형의 부정       | (기본형의 だ를 떼고)じゃ　なかったです                     | (기본형의 い를 떼고)く　なかったです |
